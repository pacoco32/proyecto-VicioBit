

\# VicioBit - Documentación de la API



\## Géneros - Paco



| Método | Endpoint | Descripción | Cuerpo |

|---|---|---|---|

| GET | `/api/generos` | Lista todos los géneros. | — |

| GET | `/api/generos/{id}` | Consulta un género por su ID. | — |

| GET | `/api/admin/generos` | Lista los géneros desde administración. | — |

| POST | `/api/admin/generos` | Crea un nuevo género. | `GeneroCrearDTO` |

| PUT | `/api/admin/generos/{id}` | Modifica un género existente. | `GeneroCrearDTO` |

| DELETE | `/api/admin/generos/{id}` | Elimina un género. | — |
